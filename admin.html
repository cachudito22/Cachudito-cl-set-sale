Conexión con GitHub

Se guarda solo en este navegador. Sin conexión, el panel funciona en modo prueba: los cambios quedan en este dispositivo y puedes exportarlos.

¿Cómo obtengo el token?
  1. En GitHub, abre Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Nombre: panel catálogo. Expiración: la que prefieras (por ejemplo 1 año).
  3. En Repository access elige Only select repositories y marca tu repositorio del catálogo.
  4. En Permissions → Repository permissions → Contents elige Read and write.
  5. Genera el token, cópialo y pégalo aquí. No lo compartas con nadie.
